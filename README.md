# UX Prototypes

A collection of UX prototypes from the eLife Pathways team.

**[View prototypes →](https://elifepathways.github.io/ux-prototypes/)**

## Prototypes

1. **Basic keyword filtering** — Testing OpenAlex keywords (or concepts) as useful filters for a demo set of eLife articles.
2. **Terms + keywords** — Adding eLife terms and summaries to the keyword filtering prototype, adding the terms as filters too.

## Adding a new prototype

1. Add a new folder to this repo (e.g. `my-prototype/`)
2. Add a card for it in `index.html`
3. Update the build step in `.github/workflows/deploy.yml` to build and copy it into `_site/`
4. Push — GitHub Actions will deploy automatically
